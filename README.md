# Deep Learning Practice

This repository is a collection of Jupyter Notebook exercises and examples focused on learning and practicing deep learning concepts. It includes introductory neural network material, data preprocessing, and recurrent neural network (RNN) topics.

## Repository contents

- `deeplearning1.ipynb` – foundational deep learning practice
- `deeplearning1-2.ipynb` – continuation of the introductory deep learning exercises
- `deeplearning2.ipynb` – further neural network and model practice
- `DeepLearning3-RNN.ipynb` – introductory RNN notebook
- `deeplearning3-rnnAdvanced.ipynb` – advanced RNN concepts and implementation
- `Part1.ipynb` – additional practice notebook
- `project2.ipynb` – project-based notebook using deep learning techniques
- `heart.csv` – heart disease dataset
- `insurance.csv` – insurance dataset
- `qoute_dataset.csv` – quote dataset used for practice

## Topics covered

- Artificial neural networks
- Deep learning fundamentals
- Recurrent neural networks (RNNs)
- Data handling with CSV datasets
- Notebook-based experimentation and learning

## Prerequisites

Before running the notebooks, make sure you have Python 3 installed along with the following packages:

- Jupyter Notebook or JupyterLab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow or Keras

## Setup

You can install the required Python packages with:

```bash
pip install jupyter numpy pandas matplotlib scikit-learn tensorflow
```

Then start Jupyter:

```bash
jupyter notebook
```

## How to use this repository

1. Clone the repository.
2. Open the notebooks in Jupyter.
3. Run the cells in order to explore the examples and exercises.
4. Modify the code to try your own experiments and learning tasks.

## Notes

This project is designed primarily as a learning and practice repository. It is useful for students or beginners exploring deep learning concepts through hands-on notebook activities.
